# 제주 라스트콜 (Jeju Last Call)

> 떠나기 전 남은 시간을, 덜 알려진 제주에서 — 팀 돌담랩

비행기 출발·렌터카 반납 시간을 지키면서 **지금 실제로 갈 수 있는 곳**만 코스로 추천하는 앱의 프론트엔드 + 백엔드.

```
jeju-lastcall/
├─ backend/    FastAPI · 시간 계산 엔진 · 지표 → 문장 번역
└─ frontend/   React + Vite + TypeScript · 모바일 웹앱
```

## 실행 (터미널 2개)

```bash
# 1) 백엔드
cd backend
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# API 문서: http://localhost:8000/docs

# 2) 프론트엔드
cd frontend
npm install
npm run dev
# http://localhost:5173  (휴대폰으로 보려면 같은 와이파이에서 http://<PC IP>:5173)
```

테스트: `cd backend && python -m unittest discover -s tests -t .`

## 데모 시각
밤에 발표 연습해도 결과가 나오도록 기본은 **데모 시각 11:00**으로 동작해요.
- 오른쪽 위 `데모 11:00` 버튼 → 실제 시각 / 09:00 / 11:00 / 13:00 / 15:00
- 주소로도 지정: `?now=14:00`, 실제 시각은 `?real`
- 진행 모드에서 "도착했어요" 등을 누르면 데모 시계가 계획된 시각으로 넘어가요.

## 화면 흐름
1. **질문형 입력** — 비행기 시간 → 부칠 짐 → 렌터카(반납 시간 / 택시·버스) → 출발 위치. 답한 항목은 아래에 쌓이고 눌러서 고칠 수 있음
2. **쓸 수 있는 시간 미리보기 + 모드 선택** — `/api/check` 결과로 "5시간 41분, 늦어도 16:41 출발"을 먼저 보여주고 관광/일/휴식 선택
3. **결과** — 공항 도착 여유(상태 카드 + 시간 막대), 모드 탭 즉시 전환, 코스 카드(누르면 상세 시트, `바꾸기`로 대체 장소와 여유 변화 비교), 지금 바로 갈 수 있는 곳
4. **진행 모드** — 장소별 "늦어도 몇 시 출발" 카운트다운, 지금 바로 공항 가면 몇 시 도착인지, 카카오맵 길찾기

## API 요약
| 메서드 | 경로 | 용도 |
|---|---|---|
| GET | /api/areas | 출발 지역 (조천·구좌·제주시) |
| POST | /api/check | 지금 출발하면 공항 몇 시 도착? 늦어도 언제 출발? |
| POST | /api/plan | 모드별 코스 계산. `sequence`로 순서 지정(바꾸기·빼기), `exclude`로 제외 |
| GET | /api/places/{id} | 시간대별 혼잡, 공항까지 시간, 데이터 근거 |

## 계산 기준 (backend/app/config.py 에서 수정)
- 공항 도착 권장: 출발 60분 전(부칠 짐 있음) / 40분 전(기내 짐만), 탑승수속 마감 30분 전으로 표시
- 렌터카: 반납 검차 15분 + 셔틀 10분
- 안전 버퍼: 마지막 이동시간의 15%, 최소 10분. 여유가 버퍼+15분 이상이면 '여유', 미만이면 '빠듯'
- 구좌 장소는 자유시간 4시간 이상일 때만 후보 (9/29 팀 결정: 조천 중심, 구좌는 확장)
- 이동시간: 직선거리 × 1.25 ÷ 평균속도(자동차 45km/h, 버스 28km/h) + 대기시간, 17~19시 공항 방향 ×1.25
